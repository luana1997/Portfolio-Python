# Aula 03 - Tipos primitivos e saída de dados.

## 🎯 Objetivo
Aprender a receber valores digitados pelo usuário por meio da função input(), transformar os dados recebidos em números, utilizar variáveis para armazenar informações, realizar operações de soma em Python e exibir o resultado utilizando a função print().

## 📚 Conteúdo estudado:
- Recebimento de dados digitalizados pelo usuário.
- Armazenamento de informações em variáveis.
- Conversão de dados de texto para números inteiros.
- Realização de operações matemáticas.
- Soma de dois números utilizando Python.
- Exibição do resultado na tela.

## 📚 Comandos utilizados
- input()
- int()
- print()

## ✅ Resultado

- Conversão dos valores digitados para números inteiros.
- Realização da soma entre os dois números.
- Armazenamento do resultado em uma variável.

## 📚 O que eu aprendi

- Utilizar comando input() para receber os dados digitalizados pelo usuário como texto.
- Realizar cálculos e converter os valores para um tipo numérico, como int().
- Usar as variáveis ​​para armazenar informações para serem utilizadas posteriormente.
 -O comando print()permite apresentar informações e resultados para o usuário.
