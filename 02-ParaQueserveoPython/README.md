# Aula 02 - Para que serve o Python?

## 🎯 Objetivo
Conhecer a linguagem Python e suas principais aplicações, preparar o ambiente de desenvolvimento e compreender os primeiros conceitos da programação.

## 📚 Conteúdo estudado:
- Introdução à linguagem Python.
- Características e aplicações do Python.
- Instalação e configuração do Python.
- Conhecimento do ambiente de desenvolvimento.
- Introdução à sintaxe do Python.
- Execução de comandos.
- Exibição de textos e informações na tela.

## 📚 Comandos utilizados

- print()
- Strings
