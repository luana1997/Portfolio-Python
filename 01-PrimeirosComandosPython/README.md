# Aula 01 - Primeiros comandos em Python

## 🎯 Objetivo
Aprender os conceitos básicos de Python, utilizando print() para exibir informações, variáveis para armazenar dados e input para receber informações do usuário. Também foram praticados números, textos e operações simples, além da diferença entre o modo interativo e a criação de scripts Python.

## 📚 Conteúdo estudado:

- Comando print()
- Exibição de mensagens e números
 -Uso de aspas simples e duplas
- Diferença entre texto e número
- Operador +
- Uso da vírgula no print()
- Variáveis
- Atribuição de valores com =
- Comando input()
- Interação com o usuário
- Modo interativo do IDLE
- Criação de scripts Python
- Execução de scripts pelo Run Module ou F5

## 📚 Comandos utilizados
- print()
- input()
- =
- ++
- ,

🏆 Desafios da aula
- Criar um programa que leia o nome de uma pessoa e exiba uma mensagem de boas-vindas.
- Criar um programa que leia o dia, mês e ano de nascimento e apresente a data formatada.
- Criar um programa que leia dois números e realize a soma dos números.

- ## ✅ Resultado

- Desenvolvi os primeiros programas utilizando print() e input().
- Pratiquei a interação entre o programa e o usuário.
- Tive o primeiro contato com desafios práticos de programação.

- Utilizar print() para exibir informações.
- Diferenciar textos de números através das aspas.
- Realizar operações matemáticas simples.
- Criar variáveis e armazenar valores.
- Utilizar = para atribuir valores às variáveis.
- Exibir diferentes variáveis utilizando print().
- Utilizar input() para receber informações do usuário.
- Criar programas com interação do usuário.
- Diferenciar o modo interativo do IDLE da criação de scripts.
- Criar e executar arquivos Python com extensão .py.
- Aprendi a utilizar os primeiros comandos básicos do Python.
